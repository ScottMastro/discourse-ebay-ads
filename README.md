# Discourse Ebay Affiliate Ads Plugin

Displays pokemon-related eBay listings from opted-in forum members as
affiliate ads — a banner on the discovery/topic pages plus a full
`/ebay` search surface. Pulls each seller's listings from the eBay
Browse API on a daily schedule, serves a weighted-random ad per
request, and tracks daily per-seller impressions, clicks, and votes.

Configured via site settings under the **Ebay Ads** category.
